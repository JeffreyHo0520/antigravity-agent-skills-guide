YAML Image Deck Breakdown

The yaml-image-deck skill compiles structured YAML representations into consistent visual slides using style locking:

  • Design System: Enforces color tokens, typography scales, and aspect ratios.
  • Layout Engine: Pre-calculated bounding boxes prevent dynamic offset overlap.
  • Validation: Runs validate_spec.py before rendering images.

Process FMEA Generator Workflow (`process-fmea-generator`)

Automates extraction from SOP Word documents (`.docx`) and Control Plan sheets (`.xlsm`) into AIAG/VDA compliant Process FMEA rows:

1. Macro Preservation

Always load workbooks with keep_vba=True to preserve embedded VBA macros in .xlsm files.

2. Merged Cell Targeting

In OpenPyXL, write formatted text directly to top-left cells: Col A (Step), Col G (Failure Mode), Col M (Effect), Col S (SEV), Col T (Causes), Col Z (OCC), Col AA (Controls), Col AG (DET).

3. RPN Formula Injection

Inject dynamic Excel formulas: Col AH = =IF(ISBLANK(S{row})," ",S{row}*Z{row}*AG{row}).
